## Important findings

1. **Confirmed submitted-link read outside the web root, now guarded by opt-in GA02.** `evals/graders/web.mjs` uses lexical containment followed by link-following reads. A temporary B copy served one synthetic outside-root canary through a submitted link; no real secret was accessed. The new metadata preflight and Node request guard block the case before submitted content reads/serving. Frozen graders and thresholds remain unchanged; current/default results retain their original grading version. See [GA02](../../evals/GRADING_AMENDMENT_GA02.md) and [proof](ga02-synthetic-proof.json).
2. **Cached original inputs could be modified and still reused; fixed during review.** In `evals/run.py`, `original_snapshot()` verifies the extraction against v2.0.0 only when `archive.sha256` is absent. With a matching marker already present, it checks that the tag archive is unchanged but not that the cached extracted tree still matches it. A synthetic modified `SKILL.md` under the cached original tree was returned unchanged by the function. This is a demonstrated resume-integrity defect, not evidence that an existing measured original input was altered. The evaluator subsequently fixed this by comparing every cached tree to a fresh tag extraction and added a tamper regression; its final test execution is recorded separately.
3. **Native build timeout cleanup is incomplete.** `evals/tools/native-runtime.py:97` sends SIGTERM, then waits 15 seconds. A child ignoring SIGTERM raises `TimeoutExpired` without a guaranteed SIGKILL/reap of that build process group. The outer handler reports an error and cleans simulator/recording state, but does not own that remaining build child. This is source-confirmed; no deliberately hung SDK process was launched for this review. Use the existing bounded process-group helper or an equivalent finally-owned termination path before relying on timeout cleanup for repeated native runs.
4. **Manual evidence contracts differ and must stay explicit.** `acceptance.json` uses the five-item 8/10 independent rubric requested for this audit, while `evals/DESIGN.md` retains a separate six-item 10/12 manual corpus rubric and 320px coverage requirement. The independent six-output review scored the requested five-item rubric at 390px mobile. It is valid evidence for that declared review, but is not completion of the separate six-item/320px corpus manual gate. No threshold or prior score was changed here.

5. **Native generated-code grading is outside the model policy boundary.** The legacy native grader launches `flutter test` in a normal host subprocess after copying submitted Dart. The prepared loopback-only native profile applies to the evaluated Codex process; it is not applied to this later grader process. `base_environment()` does not propagate that sandbox/proxy policy, and the lexical runtime check does not recognise Dart `File`, `Socket` or `HttpClient` access. Native build wrappers also execute generated tooling without that model policy. This is source-confirmed, not a claim that any measured output accessed a real secret or external host. GA02's tree/static-serving guards do not sandbox arbitrary Dart/build code. Apply a reviewed host-side execution boundary or retain this explicit limitation before claiming complete native security isolation.
