Why this fits

Creative work needs direct control. A short return path preserves spatial continuity without slowing manipulation.

What stays

Paper palette, typography, canvas geometry, input labels and caption state. Existing pointer and keyboard workflows remain.

How it is built

Original SVG + requestAnimationFrame implementation. No animation engine needed. Reduced motion resets immediately.

Examples demonstrate two bounded web interactions, not every category or agent runtime. The before versions intentionally retain baseline limitations. Native hardware, screen readers and real services are not exercised here. Changing examples restarts both previews.

01 / Understand

The job comes first.

Establish customers, task frequency, risk and devices before choosing an effect. No invented personas or industry stereotypes.

02 / Adapt

Your design stays yours.

Use existing tokens, geometry, typography and interaction patterns. Reuse a suitable mechanism, then integrate it with real state.

03 / Verify

Play it. Interrupt it. Check it.

Test drafts, focus, repeated input, error recovery and reduced motion. A successful build does not prove a good interaction.
