What to notice

The wait is not shorter. It is easier to understand, and the page does not jump when the projects arrive.

CSS skeleton pulse and a short content reveal. Reduced motion keeps a static skeleton. No animation library.

All waits, connections and uploads are simulated here. Nothing is sent. System reduced-motion settings are respected. Switching examples restarts the previews.
