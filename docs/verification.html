Evidence and limits.

A working example, a successful build and a tested agent workflow prove different things. Here is the distinction.

Version 2.0.1 is distribution maintenance: safer packaging, installation and example isolation. Its runtime workflow is unchanged from 2.0.0. The advanced 2.1.0 candidate is unreleased.

Playground
Ten original, local-only web examples. Chrome checks cover actual motion, reduced motion, keyboard, interruption and responsive layouts.
Codex
Project-local discovery and isolated CLI execution observed (0.167.0-alpha.3.2). Individual outcomes vary; this is not an agent-wide compatibility guarantee.
Claude Code
Documented format and disposable file-copy installation checked. Agent execution is blocked because this environment is not authenticated.
Native mobile
This maintenance release adds no native capability claim. Native build, grading and host limitations remain part of the unreleased advanced candidate review.
Other frameworks
The source catalogue routes relevant research. A linked library or readable Markdown file does not establish runtime compatibility.

Measured comparison

The candidate did not meet every release gate. A final filter-animation assertion failed; strict native grading remains blocked.

Checks cover executable artifact assertions. Completed means the agent returned within the 240-second budget. An output can pass checks after its agent times out. Ten tasks are development/validation; two were unseen held-out tasks. Native trials are excluded from this table.

The same advertised model and reasoning setting were used. Tooling restrictions, single runs and heterogeneous tasks limit interpretation. Independent Chrome review supplements the checks; no overall superiority claim is made. Every failure remains in the audit record.

What this does not prove

No universal accessibility certification, sustained frame-rate or battery benchmark, real-device certification or guaranteed outcome across agents. The skill is guidance, not a sandbox, and never grants release authority.
