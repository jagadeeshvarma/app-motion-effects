# Changelog

## 2.0.0

First public release of the product-aware skill.

- Added proportional customer/task context, an explicit visual contract and app-specific motion direction.
- Added source-adaptation and fit/removal checks while retaining the 63-category taxonomy and source catalogue.
- Kept project context local and clarified instruction scope and release boundaries.
- Added two original before/after playground examples, reduced-motion controls and recorded playback.
- Added contribution guidance, MIT licensing, automated checks and reproducible release packaging.

The earlier 1.x package was a local pre-release and is not published as a separate GitHub release.
